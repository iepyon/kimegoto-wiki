# ビュー（生成物）

このディレクトリの `*.md` は `python3 tools/kime.py views` が作る。**手で編集しない。**
編集しても次の再生成で消えるだけでなく、どちらが正かが分からなくなる。

| ファイル | 内容 |
|---|---|
| `open-items.md` | 会議をまたいで開いているもの一式 |
| `agenda-next.md` | 次回アジェンダ。冒頭は `なぜ` 未記入の決定、議題ごとに未決・アクションを束ねる |
| `index.md` | 全カードの一覧 |
| `metrics.md` | 判定基準のうち機械で数えられる分 |

Claude Code の Stop フックがターンの終わりに作り直すので、ふだんは意識しなくてよい。
