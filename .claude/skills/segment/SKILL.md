# Pass 1 — 論点の切り出し

共通規約は `CLAUDE.md` が正典。判定基準の正本は `prompts/pass1_segment.md`。
以下は本スキル固有の手順。

## 手順

1. 対象の会議を決める。無ければ `projects/<slug>/meetings/MTG-YYYYMMDD/` を作り、
   `transcript.md` を置いてもらう
2. `prompts/pass1_segment.md` を読み、そこに書かれた指示をそのまま実行する
3. `role-mapping.yaml` を読む（役割ラベルの表記を合わせるため）
4. `meetings/MTG-YYYYMMDD/segments.yaml` に書き出す
5. **人間に粒度の確認を求めて、そこで止まる**

## このパスでやらないこと

- 内容の要約・抽出（Pass 2 以降）
- 引用を取ること
- カードを作ること

出力は境界と見出しだけ。10行程度で済むので、人間がこの時点で粒度を直せる。
論点の適正な粒度は3回ほど回さないと決まらない。その調整をここで安く吸収する。

## 人間に確認すること

「この切り方でよいか」を必ず聞く。細かすぎる／粗すぎると感じたら、
分割・統合してから Pass 2 に進む。ここを飛ばすと後戻りが高くつく。

## 未登録の役割ラベル

`role-mapping.yaml` に無い役割ラベルが出てきたら、`segments.yaml` の末尾に
`# 未登録の役割ラベル: [〇〇]` として報告する。勝手に既存の役割へ寄せない。
